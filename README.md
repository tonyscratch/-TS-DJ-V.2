# Tony Scratch Dj (TS Dj)

An Android DJ app for the Galaxy S23 Ultra, built to be played with the S Pen.
Orange on black, landscape only. Version 0.2.

---

## 1. What's in this version

### Decks

| Feature | How it works |
| --- | --- |
| Two decks | Load songs from your phone, play, CUE (hold to preview), tempo ±8 / 16 / 50%, eject |
| **Keylock** | On by default (LOCK button). Changing the tempo keeps the song in its key. Turn it off for the classic vinyl sound |
| **Tempo stays when you change songs** | The tempo fader keeps its position when you load a new track (Settings › Keep tempo when loading) |
| Key shift & key match | KEY pad page: move the key ±3 semitones, reset, or MATCH (moves it the smallest amount to mix with the other deck) |
| Sync | Matches tempo and lines up the beats |
| Scratching | Drag the jog wheel, **or drag the waveform** while the track plays. With the S Pen, press harder for a tighter grip |
| Moving through a song | Drag the waveform (scratches while playing, moves the playhead while stopped), or tap/drag the **track overview** next to it to jump anywhere |
| Slip mode | SLIP button: after a scratch, loop, reverse or roll, the track carries on exactly where it would have been |
| Quantize | Q button: cues, loops and jumps snap to the beat |
| Auto-gain | Quiet and loud tracks come out at a similar volume |

### The switchable pad section

Each deck has 8 pads. Use **◀ ▶** or tap the page name to switch what they do:

| Page | What the pads do | Bottom row |
| --- | --- | --- |
| HOT CUES | 8 hot cues per track (saved). Tap an empty pad to save, tap to jump | DEL: tap a pad to delete its cue |
| LOOP | Auto loops of 1/4 to 32 beats | ½, ×2, IN, OUT, exit |
| ROLL | Hold for a loop roll (1/32 to 4 beats); the track keeps going underneath | — |
| BEAT JUMP | Jump −32, −16, −4, −1, +1, +4, +16, +32 beats | — |
| EFFECTS | 8 effects per group; tap to switch on/off (some are hold or tap-once) | Group button, **intensity knob**, second knob |
| SAMPLER | Play the 8 sounds in the current bank | Bank, volume, stop |
| KEY | Key −3…+3, reset, match | Current key → new key, keylock |
| MY PADS | 8 pads you set up yourself (any action) | EDIT: change or clear a pad |

### Effects (26)

The pad shows the effect's short name. The **left knob is the intensity**; the right knob is the second setting (beats, size, filter…). Effects follow the track's BPM.

| Group | Effects |
| --- | --- |
| ECHO | Echo, Echo Out, Delay, Ping Pong, Dub Echo, Spiral |
| SPACE | Reverb, Space, Flanger, Phaser, Chorus, Filter Sweep, Auto Pan, Robot |
| BEAT | Trans (gate), Roll (hold), Reverse Roll (hold), Brake (tap), Backspin (tap), Reverse, Censor (hold), Pitch |
| LO-FI | Bitcrusher, Distortion, Noise, Vinyl |

Brake and Backspin: the left knob sets how long they take; set the right knob to ON to carry on playing afterwards.
Each deck also keeps its **FILTER** knob in the mixer.

### Sampler and sound banks

| Bank | Sounds |
| --- | --- |
| DJ FX | Air Horn, Siren, Dub Siren, Laser, Rewind, Gunshot, Bomb Drop, Scratch |
| BUILD-UPS | Riser, Downlifter, Noise Up, Noise Down, Impact, Sub Drop, Reverse Cymbal, Vinyl Stop |
| DRUMS | Kick, Snare, Clap, Hi-Hat, Open Hat, Rim, Tom, 808 |
| HYPE | Whistle, Cowbell, Zap, Drum Roll, Bell, Alarm, Woosh, Glitch |
| MY SOUNDS 1 & 2 | Your own sounds: tap an empty pad and pick any audio file (up to 30 seconds is used) |

All built-in sounds are generated by the app itself, so there's nothing to download and no copyright problems.

### Shortcuts

The row in the top bar holds your own shortcut buttons. Tap **+**, choose a category (Deck, Loops & jumps, Hot cues, Effects, Sounds, Mixer), choose deck A, B or both, and tap the action. Tap the pencil to move (◀ ▶) or remove (✕) them. The **MY PADS** page works the same way, per deck.

### Library

| Feature | How it works |
| --- | --- |
| Folders | Browse your phone folder by folder (sidebar tree, plus sub-folders at the top of the list and a path bar) |
| Sort | Tap a column title: TRACK, BPM, KEY or TIME. Tap again to reverse |
| ±BPM | How much each track would need to speed up or slow down to match the chosen deck (green = easy) |
| ±KEY | Key difference to the chosen deck: ✓ = mixes well, ±1 = one semitone off, otherwise the semitones needed |
| Compare to deck | Choose which deck the differences are measured against |
| Key match / BPM ±6% | Filters that show only tracks that mix well |
| History | Every track you play for 45 seconds or more (marked with a tick) |
| Automix | Press and hold a track › Automix: add to list / play next. Press AUTO in the top bar; it loads, syncs and crossfades for you |
| Crates | Your own lists. Press and hold a track › Add to crate |

### Mixer, recording and the rest

| Feature | How it works |
| --- | --- |
| Mixer | HI, LOW and FILTER per deck, channel faders, level meters, crossfader |
| Headphone cue | Headphone buttons A/B. Needs a stereo splitter cable and Settings › Split output (left = speakers, right = headphones) |
| Recording | REC records what you hear (decks, effects and sampler) to Music/TS Dj |
| Recordings screen | Play back, rename, share and delete mixes |
| YouTube Mix | Two YouTube players, Video or Audio view, volume and crossfade (see section 4) |
| S Pen screen | Grip strength, pressure curve, pen-button deck, hover zoom |
| Settings | Keylock default, keep tempo, quantize, auto-gain, auto key match, key names (8A or Am), split output, Automix crossfade length |

Controls you might not guess:

- **Knobs and faders:** drag up/down. Double-tap a knob or fader to reset it.
- **BPM number on a deck:** tap it to double/halve a wrong BPM, set the beat grid, reset tempo, change tempo range, or eject.
- **Key on a deck:** green = mixes with the other deck, amber = one semitone off.
- **Crossfader:** double-tap to centre.

## 2. Getting the app onto your phone

You don't need to know how to code. Pick **one** of these two ways.

### Way A — let GitHub build it for you (no software to install)

1. Make a free account at **github.com**.
2. Press **+** (top right) › **New repository**. Name it `TSDj`, choose **Private**, press **Create repository**.
3. On the new page, click **uploading an existing file**.
4. Unzip `TSDj.zip` on a computer, open the `TSDj` folder, select **everything inside it** and drag it into the GitHub page. Press **Commit changes**.
5. Check the `.github` folder was uploaded (some computers hide folders that start with a dot).
   If you don't see `.github/workflows/build.yml` in the file list:
   press **Add file › Create new file**, type `.github/workflows/build.yml` as the name,
   paste in the contents of that file from the zip, and press **Commit changes**.
6. Open the **Actions** tab. A run called **Build TS Dj** starts by itself and takes about 5–10 minutes.
   A green tick means it worked.
7. Click the run, scroll to **Artifacts**, and download **TSDj-apk**. It's a zip with `app-debug.apk` inside.
8. Send `app-debug.apk` to your phone (email it to yourself, Google Drive, or a USB cable) and tap it to install.
   The first time, Android asks you to allow installing apps from that source: tap **Settings** › turn on **Allow from this source** › go back › **Install**.

Every time you upload changed files, GitHub builds a fresh APK the same way.

### Way B — Android Studio on a computer

1. Install **Android Studio** from developer.android.com/studio (free, Windows / Mac / Linux).
2. Unzip `TSDj.zip`. In Android Studio choose **Open** and pick the `TSDj` folder.
3. Wait while it downloads what it needs (the bar at the bottom; the first time can take 10+ minutes).
   If it offers to upgrade anything, it's fine to say **yes**.
4. On your phone, turn on **Developer options**: Settings › About phone › Software information › tap **Build number** 7 times.
   Then Settings › Developer options › turn on **USB debugging**.
5. Plug the phone in with a USB cable and accept the "Allow USB debugging?" prompt on the phone.
6. Your phone appears at the top of Android Studio. Press the green **▶ Run** button.

## 3. YouTube setup

### No setup needed: share songs into the app

- **From the YouTube Music (or YouTube) app:** open a song › **Share** › **Tony Scratch Dj**. It loads onto a free YouTube deck and opens YouTube Mix, with the song's title filled in.
- **Paste a link:** YouTube Mix › **Browse** › **Link** › **Paste**, then *Load to A* or *Load to B*.

### Signing in (to browse your playlists, liked songs and search)

Google only allows sign-in for apps registered in Google Cloud. Because you're the developer of this app, you register it once (about 15 minutes):

1. Go to **console.cloud.google.com** and sign in with the Google account that has YouTube Premium.
2. Create a project (top bar › project picker › **New project**), name it `TS Dj`.
3. **APIs & Services › Library** › search **YouTube Data API v3** › **Enable**.
4. **APIs & Services › OAuth consent screen** (may be called **Google Auth Platform**):
   choose **External**, app name `TS Dj`, add your email where asked, save.
   Under **Audience / Test users**, **add your own Gmail address**.
5. **APIs & Services › Credentials › Create credentials › OAuth client ID**:
   - Application type: **Android**
   - Package name: `com.tonyscratch.tsdj`
   - SHA-1 certificate fingerprint:
     `CB:51:E6:C2:96:5F:FD:63:5D:19:8B:FA:0F:CB:77:30:66:BE:2F:36`
   - Press **Create**.
6. Wait a few minutes, then open Tony Scratch Dj › YouTube Mix › **Sign in with Google**.
   If Google says *"Google hasn't verified this app"*, tap **Advanced › Go to TS Dj (unsafe)** — that's expected for your own private app.

If sign-in fails, the app now shows the reason in red under **Browse**:

| Message | What to do |
| --- | --- |
| Google doesn't recognise this app yet (error 10) | The Android OAuth client is missing or the package name / SHA-1 doesn't match exactly (step 5). Wait 5 minutes after fixing |
| Sign-in didn't finish / "Access blocked" | Add your Gmail as a Test user (step 4) |
| No internet connection (error 7) | Check Wi-Fi or mobile data |
| Google Play services needs updating | Update Google Play services from the Play Store |
| YouTube Data API v3 has not been used in project… | Enable the API (step 3) |

That fingerprint belongs to the signing key included in this project (`app/tsdj-dev.jks`), so it stays the same for every build. Keep your GitHub project **private**.

## 4. YouTube rules this app follows (and why)

YouTube only allows other apps to play its videos through its own player. So in TS Dj:

- YouTube songs play in YouTube's player, and you mix them with **volume and the crossfader**.
  EQ, filters, pitch, sync, scratching and recording don't apply to YouTube songs.
- The player always stays on screen while it plays, at least 200 × 200, with nothing drawn over it.
  That's why Audio view keeps a small square showing the song's cover art.
- Leaving the YouTube Mix screen, or switching to another app, pauses YouTube.

Songs stored on your phone get the full DJ treatment.

## 5. Not in this version yet

- **Stems** (separating vocals, drums and melody): VirtualDJ does this with an AI model; it isn't in TS Dj.
- **4 decks, DJ controllers (MIDI), video effects and broadcasting** — VirtualDJ features not added yet.
- **Full S Pen Air actions**: TS Dj responds to media keys, which some phones send from the pen button.
  Complete Air actions support needs Samsung's S Pen Remote SDK, planned for later.
- **M4A recording**: recordings are WAV (best quality, about 11 MB per minute).
- **Cast to TV.**

## 6. If something goes wrong

- **Upgrading from version 0.1:** install over the old version; your hot cues and analysis are kept.

- **The GitHub build shows a red ✗:** open the run, click the failed step, copy the red error lines and paste them to Claude.
- **"Couldn't load this track":** the file may be damaged or protected (DRM).
- **Sound crackles:** close other apps. TS Dj automatically increases its audio buffer if the phone can't keep up.
- **YouTube video says the owner doesn't allow it:** some videos can't be played in other apps; try another version of the song.

## 7. How the code is organised

```
app/src/main/java/com/tonyscratch/tsdj/
  MainActivity.kt         app start, full screen, permissions, media keys
  DjViewModel.kt          the app's brain: decks, effects, sampler, shortcuts, automix, history
  audio/                  sound engine: decoding, decks, keylock (Stretcher), effects, sampler,
                          built-in sounds (SoundSynth), mixer, recorder, BPM & key
  data/                   phone library, saved analysis & hot cues, crates, history, shortcuts,
                          settings, recordings, the action list for shortcuts
  youtube/                YouTube Mix state and the YouTube Data API
  ui/                     screens: Mixer, pad section, Library, YouTube Mix, S Pen, Recordings, Settings
  ui/components/          knobs, faders, pads, jog wheel, waveforms, track overview, icons
  ui/theme/               colours and fonts
```
